🧠 What is Sudoku?

Sudoku is a logic-based puzzle where you fill a 9×9 grid so that:

  • Each row contains numbers 1 through 9 with no repeats
  • Each column contains numbers 1 through 9 with no repeats
  • Each of the nine 3×3 boxes (sub-grids) contains numbers 1 through 9 with no repeats

✅ Basic Rules

  • You cannot repeat a number in any row
  • You cannot repeat a number in any column
  • You cannot repeat a number in any 3×3 box
  • You're usually given some numbers to start, called "clues" or "givens".

🛠️ Beginner Strategies

  1. Scan for missing numbers:
    Look for rows, columns, or boxes with many numbers already filled. Find which number is missing and see if it can go in only one possible position.
  2. Use the "Only One Possible Place" method:
    If a number can go in only one cell in a row/column/box, put it there.
  3. Pencil marks:
    Write small possible numbers in empty cells to help eliminate options later.
  4. Crosshatching:
    Focus on a number (e.g. 5), and scan all rows and columns to narrow down where 5 can go in each box.
